MONEQ DEAL FINDER — iPhone PWA package

이 폴더는 아이폰 홈 화면에 추가할 수 있는 PWA 배포 패키지입니다.

중요: ZIP을 아이폰에 다운로드하는 것만으로 앱 설치가 되지는 않습니다.
반드시 HTTPS 주소로 웹에 배포해야 합니다. 배포 후 iPhone Safari에서 주소를 열고:
공유 버튼 → 홈 화면에 추가

포함:
- index.html: 웹앱
- manifest.webmanifest: PWA 설정
- sw.js: 오프라인 앱 셸 캐시
- icons/: 홈 화면 아이콘

현재 기능:
- 매물 직접 등록/삭제
- 예상 재판매 차익 계산
- 키워드/플랫폼/가격 조건 저장
- 브라우저 알림 권한 요청 및 앱이 열린 상태에서 조건 일치 매물 알림
- 플랫폼 검색 URL 바로가기
- 데이터는 해당 기기의 브라우저 localStorage에 저장

현재 미포함:
- 당근/번개장터 자동 매물 수집
- 서버 기반 가격 시세 조회
- 앱이 완전히 종료된 상태의 자동 푸시 알림

위 세 기능은 플랫폼의 허용된 API/제휴 접근 권한과 별도 서버/푸시 구성이 필요합니다.
서비스의 로그인·접근 제한을 우회하는 수집 방식은 포함하지 않았습니다.

무료 배포:
GitHub Pages 등 HTTPS 정적 호스팅에 폴더 안 파일을 업로드하면 됩니다.
배포 계정 생성/로그인 및 공개 설정은 계정 소유자의 승인이 필요하므로 이 패키지에서 대신 처리하지 않았습니다.
